# JetBrains extensions

Plugins for JetBrains IDEs. Each extension is in its own folder with its own README and build.

| Extension | What it does |
|---|---|
| [Review Marks](review-marks/) | Mark code as reviewed while you read it. A line you edit inside reviewed code turns amber until you review it again. A sidebar, notes, progress, focus modes and pause reminders help you read in small pieces. |
